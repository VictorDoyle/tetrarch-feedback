# Tetrarch feedback

Public issue tracker for [Tetrarch](https://tetrarch-ide.com). This repository has no source code.

File bugs and product feedback in [Issues](../../issues).

## How to report

In the app, use **Help → Report Issue**. That opens a new issue with your Tetrarch version and system details filled in. Add:

- what you were doing
- what you expected
- what happened instead
- steps to reproduce, if you can

If you open an issue yourself, also include the version from **Help → About** and your macOS version.

## Leave out

API keys, tokens, passwords, `.env` files, and private source. Redact logs before pasting them.

Pull requests are not accepted.
